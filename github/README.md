# Zyvar Hindi 0549

A study site for **Cambridge IGCSE Hindi as a Second Language (0549)**, for exams in 2027, 2028 and 2029.

- **Read:** eight practice sets covering Exercises 1 to 4, with tap-to-translate words and instant checking.
- **Write:** 28 annotated A* model answers (emails, reports, articles, essays and reviews), the official marking criteria in plain English, and layout guides for every text type.
- **Words:** linking words, idioms, A* sentence frames, topic vocabulary, flashcards and spelling quizzes.
- **Papers:** links to the official Cambridge specimen papers, past papers, mark schemes and examiner reports.

The whole site is one file, `index.html`, with no build step or server needed.

## Features that need Claude

Photo marking, the tutor chat, new reading passages, new A* samples and read-aloud use Claude's artifact runtime. They work when the page is opened as a Claude artifact. On GitHub Pages or any other host, these buttons hide themselves and everything else works normally.

## Sources

Exam structure and marking criteria come from Cambridge's published 0549 syllabus (2027–2029), the 2027 specimen paper and mark scheme, and the November 2024 Principal Examiner Report. Passages and model answers are original. Email presets, theme vocabulary, the word bank and spelling traps come from class notes by D.M.
